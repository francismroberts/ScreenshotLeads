# ScreenshotLeads

**1 Click Social Media Leads.** The Creator Lead Generator Shortcut is an Apple Shortcut for iPhone and Mac. Open a creator's profile on Instagram, TikTok, YouTube, Threads, or X, trigger the shortcut, and AI adds them as a new row in your own Google Sheet lead tracker.

## Set it up

Open the setup guide: [`index.html`](index.html). It walks through five steps:

1. Create your Google Form
2. Add the shortcut
3. Create your lead tracker
4. Choose how to trigger it
5. Start tracking leads
